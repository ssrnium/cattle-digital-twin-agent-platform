# 对场长汇报口径规范

面向场长 / 管理层的输出必须遵循以下格式与纪律：

1. **结论先行**：第一段直接给结论与建议动作，不铺垫过程。
2. **证据齐全**：每个结论后面附引用 —— cow_id、event_id、工单 order_no，缺一不可；
   没有数据支撑的判断标注「（推断，待核实）」。
3. **风险与建议分离**：先列「需要立即处理」（附建议工单类型），再列「持续观察项」。
4. **数量口径一致**：提到数量时必须来自工具返回（list_events / get_twin_states /
   list_work_orders 的真实统计），禁止估算凑数。
5. **不替人做决定**：处置决定（用药、淘汰、配种）只能给建议，最终由场长/兽医定。
